Controle de Modo Teste

TESTE = só admin vê. ATIVO = todos veem. MANUTENÇÃO = escondido de todos. Exemplo: Menina da Roça em TESTE só você acessa via Visualizar.

Como usar o Modo Teste

  1. Crie a página ex: menina-da-roca.html e suba pro GitHub
  2. No painel, deixe ela em TESTE
  3. Clique em Visualizar - abre com ?admin_preview=1 só pra você
  4. Quando estiver pronta, clique em Ativar - ela entra no menu de todos sem precisar mexer no menu
